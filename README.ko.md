# Git Scope

[English documentation](README.md)

![Git Scope 미리보기](images/preview.gif)

> Git Graph의 개념을 현대적으로 개선해 처음부터 다시 만든 클린룸 재구현입니다. 원본 소스 코드에서 파생되지 않았습니다.

커밋 그래프를 시각화하고 그래프에서 직접 Git 작업을 실행할 수 있는 VS Code / Cursor 확장 프로그램입니다.

## 사용법

상태 표시줄 왼쪽의 **Git Scope**를 클릭하거나 명령 팔레트(`Cmd+Shift+P`)에서 **Git Scope: View Git Graph**를 실행하세요. 그래프에서 `Cmd/Ctrl+F`를 누르면 검색 위젯이 열리고, `Escape` 또는 × 버튼으로 닫을 수 있습니다.

## 기능

- **커밋 그래프**: 브랜치별 색상 레인, 로컬·원격·태그·스태시·fixup 뱃지, HEAD와 worktree 표시, 증분 로딩, 지속적인 라인 강조를 지원합니다. 뱃지 아이콘 색상은 해당 그래프 레인 색상과 일치합니다.
- **커밋 상세 정보**: 인라인 메타데이터, 파일 아이콘 테마가 적용된 트리 또는 목록, 파일별 diff, 파일 열기와 경로 복사, 커밋 간 비교를 지원합니다.
- **유효 변경량**: 빈 줄과 주석만 있는 변경을 제외한 순수 유효 라인 증감을 계산합니다. 추가·삭제 수를 따로 제공하며 미지원 형식이나 바이너리 파일도 명확하게 구분합니다.
- **작성자 통계**: 현재 브랜치 또는 모든 ref의 전체 히스토리를 기준으로 기간별 커밋 수, 아바타, 이름, 이메일을 확인할 수 있습니다. `.mailmap`으로 정규화된 작성자 정보는 자동으로 합쳐집니다.
- **커밋 타임라인**: 일·월·연도 단위의 활동량 라인 그래프, 작성자 필터, 날짜별 상세 정보, 선택 기간에 따른 커밋 그래프 필터링을 지원합니다.
- **Git 작업**: 체크아웃, 브랜치 생성·삭제·이름 변경, merge, rebase, cherry-pick, revert, 커밋 메시지 수정과 커밋 제거, 태그, fixup/autosquash, stash, fetch, push, pull을 지원합니다. 위험한 작업은 실행 전에 확인합니다.
- **브랜치 동기화**: ahead/behind 상태를 반영한 안전한 원격 체크아웃, 기존 로컬 브랜치의 fast-forward 전용 갱신, 현재 브랜치의 일반 upstream pull, HEAD나 워킹트리를 바꾸지 않는 다른 로컬 브랜치 pull을 지원합니다.
- **충돌 상태 인식**: 진행 중인 merge, rebase, cherry-pick, revert 상태와 미해결 파일 수를 그래프에서 확인하고 작업을 안전하게 중단할 수 있습니다. 충돌 가능한 작업은 Git 오류가 발생해도 즉시 상태를 갱신합니다.
- **브랜치 정리**: glob 필터, Tree/List 보기, 원격 브랜치 표시 제어, 로컬 대응 브랜치가 없는 원격 브랜치 숨김, 저장소별 로컬·원격 브랜치 개별 숨김을 지원합니다.
- **브랜치 드래그앤드롭**: 로컬·원격 브랜치 뱃지 사이에서 merge와 rebase 흐름을 시각적으로 수행할 수 있습니다.
- **향상된 git reset**: 커밋 또는 `HEAD~N`을 기준으로 soft, mixed, hard reset을 실행할 수 있으며, 커밋 되돌리기 단축 기능과 영향받는 히스토리를 보여주는 drag-to-reset 미리보기를 제공합니다.
- **스태시 관리**: 스태시 생성, 상세 확인, apply, pop, 이름 변경, drop을 지원합니다. tracked/untracked 파일과 diff를 확인하고 orphan 스태시를 식별하며 여러 항목을 패널에서 관리할 수 있습니다.
- **Worktree 관리**: worktree 목록 확인, 추가, 제거, 이동, 복구, 잠금을 지원하며 그래프 뱃지와 창 열기 기능을 제공합니다.
- **IDE 스타일 검색**: 결과 이동, 대소문자 구분, 단어 단위, 정규식, 검색 기록, 결과 없음 표시를 지원하는 커밋 검색을 제공합니다.
- **반응형 다이얼로그**: 모달 작업에서 키보드 입력과 제출·닫기, 포커스 제한, 종료 후 포커스 복원을 지원합니다.
- **Fetch prune**: fetch 과정에서 더 이상 존재하지 않는 원격 추적 ref를 정리할 수 있습니다.
- **아바타와 공동 작성자**: 캐시된 GitHub 프로필 이미지, Gravatar 대체 이미지, `.mailmap` 기반 작성자 정보, Claude·Codex·Cursor 공동 작성자 전용 아이콘을 지원합니다.
- **자동 새로고침**: Git Scope 작업, 터미널 명령, Source Control 변경, linked worktree와 submodule의 변경을 효율적으로 반영합니다. 무시된 파일과 숨겨진 패널은 불필요한 백그라운드 Git 작업을 발생시키지 않습니다.

## 텔레메트리

Git Scope는 사용되는 기능을 파악하고 오류를 개선하기 위해 확장 프로그램 활성화, 그래프 열기, Git 작업 이벤트의 작업명·성공 여부·소요 시간만 익명으로 수집합니다. **저장소 내용은 수집하지 않습니다.** 커밋 메시지, 브랜치명, 파일 경로, 원격 URL, 오류 내용은 수집 대상이 아닙니다. 전체 이벤트 목록은 [`telemetry.json`](telemetry.json)에서 확인할 수 있습니다.

텔레메트리는 VS Code의 `telemetry.telemetryLevel` 설정을 따르며, `off`로 설정하면 비활성화됩니다.

